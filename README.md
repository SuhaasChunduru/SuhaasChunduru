## PROJECTS

### Brain Tumor Segmentation — Twin SE-UNet
> Research-grade medical imaging model for multi-region tumor boundary review

`Python` `TensorFlow` `Keras` `U-Net` `Medical Imaging`

- U-Net with **twin squeeze-and-excitation blocks** for 2D multi-region segmentation (ET / TC / WT)
- Trained on **4-modality BraTS MRI** — Dice **0.87 whole tumor · 0.82 enhancing · 0.81 core**
- Preprocessing pipeline: bias-field correction, intensity normalization, augmentation

**[View repository →](https://github.com/SuhaasChunduru/Brain-tumor-Detection-)**

### AI Exam Shield — On-Device Proctoring
> Exam integrity without shipping a single frame of video to a server

`TypeScript` `Electron` `TensorFlow.js` `Computer Vision`

- Cross-platform **Electron** desktop app with fully **on-device TensorFlow.js** inference
- Real-time face and object detection via **BlazeFace** and **COCO-SSD**
- Six violation signals: face detection, gaze tracking, prohibited objects, audio monitoring, tab-switch and fullscreen enforcement
- Zero data transit, zero privacy exposure, no server GPU bill

**[View repository →](https://github.com/SuhaasChunduru/ai-exam-shield)**

### FAQFlow AI — RAG Chatbot Generator
> Upload your FAQ documents, get back an embeddable support widget

`FastAPI` `Next.js` `ChromaDB` `RAG` `JWT`

- Ingests **PDF / DOCX / TXT**, chunks and embeds them into a **ChromaDB** vector store
- Retrieves top-k context before generation so answers stay **grounded in the source documents**
- **FastAPI** backend with JWT auth, **Next.js** dashboard, embeddable widget for any site

**[View repository →](https://github.com/SuhaasChunduru/faq-flow-gen-ai)**
